# UI Ecosystem 2026 — decisões do projeto

## Fundação
- **shadcn/ui**: primitives e padrões de acessibilidade.
- **Shadcn Blocks**: principal referência de ecommerce (product card, checkout, order summary, trust strip).
- **21st.dev**: curadoria/benchmark de componentes.
- **Ruixen UI**: inspiração para marketing blocks específicos.
- **Magic UI**: apenas microinterações discretas.
- **Kokonut UI**: principal inspiração para Admin e pagamentos.
- **React Bits / Aceternity UI**: inspiração seletiva; efeitos pesados rejeitados.

## Regras
1. Não instalar oito bibliotecas no bundle.
2. Produto e conversão têm prioridade sobre efeitos.
3. Mobile 360/390/430 é fonte de verdade.
4. Nenhum dado de confiança pode ser inventado.
5. O visual deve parecer uma única marca, não um catálogo de componentes.
