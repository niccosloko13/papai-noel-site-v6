DESTINOS DE COMPRA

Checkout · Mercado Livre e Shopee

Cole os links oficiais dos anúncios do seu kit. Quando um link válido estiver salvo, a opção de compra aparecerá automaticamente no site. Campos vazios permanecem indisponíveis.

Use o link público do produto, e não um checkout temporário com dados de comprador. O valor do frete e o pagamento serão informados pela própria plataforma.

Para testar, salve os links, abra a loja e confirme se cada botão leva ao anúncio correto. Não consideramos um clique como venda confirmada.
ANÚNCIOS · PRONTO PARA TRÁFEGO

Confira as fontes de medição e gere links para cada criativo. Com o ID correto salvo, o Pixel só carrega no site quando o visitante aceita a medição de marketing. Eventos de compra exigem confirmação de pagamento.

INTEGRAÇÕES

Pixels e mensuração

Insira somente IDs reais das suas contas. O Pixel da Meta depende do consentimento do visitante. As integrações externas precisam de implementação e verificação antes de serem marcadas como ativas.

Os eventos internos são registrados pela loja. Purchase não deve disparar apenas porque o cliente clicou em “Já fiz o Pix”.
LINKS DE CAMPANHA

Gerador de URL com UTM

Use uma URL diferente para cada criativo. Assim identificamos a origem e o desempenho dentro do painel.
