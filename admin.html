Como funciona

  1. O checkout cria um pedido único.
  2. O QR Code recebe o valor exato e o identificador do pedido.
  3. O cliente informa que pagou.
  4. O pedido vira “Pagamento informado”.
  5. Você confere no banco e confirma manualmente como “Pago”.
Este Admin usa localStorage nesta fase. Antes de publicar em produção, proteja a área administrativa com autenticação e backend.
